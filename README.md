# Консольний застосунок для обробки товарів

## Призначення

Проєкт реалізує лабораторну роботу № 3: читає товари з CSV-файлу, перевіряє записи, обчислює підсумкові показники та виводить звіт у консоль і файл.

## Модель даних

`BakeryItem` — абстрактний sealed-базовий клас зі спільними властивостями. Об'єкти створюються фабриками `Bread.create(...)`, `Pastry.create(...)` або `BakeryItem.fromCsv(...)`, які перевіряють інваріанти до виклику конструкторів. Підтипи — `Bread` і `Pastry`; кожен реалізує власний розрахунок маржі. Контролер викликає `calculateMargin()` через спільний тип, без перевірок підтипу.

Категорії визначені enum `BakeryKind`: `BREAD` (`хлiб`), `PIE` (`пирiг`), `CONFECTIONERY` (`кондитерський`), `COOKIE` (`печиво`) і `BAKED_GOOD` (`випiчка`). Хлібна маржа враховує 5% виробничих витрат від собівартості; маржа інших виробів — 10% витрат на пакування.

`equals()` і `hashCode()` порівнюють вироби за назвою, категорією, вагою, собівартістю та ціною.

## Порівняння з лабораторною роботою № 2

Збережено формат CSV, валідацію рядків, загальну вагу, пошук найдорожчого товару та структуру звіту. У ЛР3 формулу маржі винесено в підтипи: для однакових прикладових даних середнє значення змінилося з `22.00 грн` на `19.95 грн` через додаткові витрати.

## Формат вхідного файлу

Кожен рядок містить п'ять полів, розділених крапкою з комою:

```text
Назва;Тип;Вага;Собівартість;Ціна
Хліб пшеничний;хлiб;500;22.00;38.00
Печиво;печиво;200;30.00;58.00
```

Файл має бути в UTF-8. Десятковим роздільником може бути крапка або кома.

## Перевірка даних

- Має бути рівно п'ять полів; назва й тип не можуть бути порожніми.
- Тип має відповідати одному зі значень `BakeryKind`.
- Вага має бути цілим невід'ємним числом.
- Собівартість і ціна мають бути скінченними невід'ємними числами.
- Некоректний рядок потрапляє до звіту з номером і причиною помилки; інші рядки обробляються далі.

## Збірка та запуск

Потрібна Java 21.

Windows PowerShell:

```powershell
.\mvnw.cmd verify
.\mvnw.cmd package
java -jar target/kzp-labv25-chyvantukh-3.0.0-all.jar --input data/input.csv --output data/report.txt
```

Windows Command Prompt:

```cmd
mvnw.cmd verify
mvnw.cmd package
java -jar target/kzp-labv25-chyvantukh-3.0.0-all.jar --input data/input.csv --output data/report.txt
```

macOS та Ubuntu:

```bash
./mvnw verify
./mvnw package
java -jar target/kzp-labv25-chyvantukh-3.0.0-all.jar --input data/input.csv --output data/report.txt
```

Довідка та версія:

```text
java -jar target/kzp-labv25-chyvantukh-3.0.0-all.jar --help
java -jar target/kzp-labv25-chyvantukh-3.0.0-all.jar --version
```

Коди завершення: `0` — успіх, `1` — помилка аргументів або читання, `2` — помилка запису звіту.
