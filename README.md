# Консольний застосунок для обробки товарів

## Призначення

Програма зчитує дані про товари з файлу, переданого через `--input`, перевіряє кожен запис,
відкидає некоректні рядки, обчислює агреговані показники та формує звіт у консоль
і в текстовий файл, переданий через `--output`.

## Формат входу

Файл CSV містить по одному товару в одному рядку. Поля в рядку розділяються крапкою з комою.
Формат запису:

`Назва;Тип;Вага;Собівартість;Ціна`

Приклад:

```text
Хлiб пшеничний;хлiб;500;22.00;38.00
Печиво;печиво;200;30.00;58.00
```

Файл зберігається в кодуванні UTF-8.

## Збірка та запуск

Для Windows:

```bash
mvnw.cmd verify
mvnw.cmd package
java -jar target/kzp-labv25-chyvantukh-1.0.0.jar --input data/input.csv --output data/report.txt
```

Для macOS та Ubuntu:

```bash
./mvnw verify
./mvnw package
java -jar target/kzp-labv25-chyvantukh-1.0.0.jar --input data/input.csv --output data/report.txt
```

Щоб переглянути версію застосунку:

```bash
java -jar target/kzp-labv25-chyvantukh-1.0.0.jar --version
```

Команда виводить `1.0.0`.

Щоб переглянути довідку про призначення програми, доступні параметри та приклад запуску:

```bash
java -jar target/kzp-labv25-chyvantukh-1.0.0.jar --help
```

Програма завершується з кодом `0` після успішного виконання, з кодом `1`, якщо не вдалося прочитати вхідний файл, або з кодом `2`, якщо не вдалося записати звіт.

## Приклад роботи

Після запуску програма читає дані з файлу, вказаного в `--input`, і виводить:

- коректні товари;
- список помилок для некоректних рядків;
- загальну вагу товарів;
- середній маржинальний прибуток;
- найдорожчий товар.

Результат також записується у файл, вказаний у `--output`.

## Примітка

Проєкт збирається за допомогою Maven Wrapper і використовує Java 21.
