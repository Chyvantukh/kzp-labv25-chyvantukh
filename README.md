# Консольний застосунок для обробки товарів

## Призначення

Цей проєкт реалізує лабораторну роботу № 2 для обробки даних про хлібобулочні вироби у CSV-файлі. Програма зчитує записи з CSV-файлу, вказаного через `--input`, перевіряє їхню коректність, відкидає некоректні рядки, обчислює агреговані показники та формує звіт у консоль і у текстовий файл.

## Модель даних: BakeryItem

Клас `BakeryItem` описує один товар і зберігає такі поля:

- `name` — назва товару;
- `type` — тип виробу;
- `weightG` — вага у грамах;
- `cost` — собівартість;
- `price` — ціна продажу.

Клас має конструктор та геттери для доступу до значень. Для створення об'єкта з CSV-рядка використовується статичний метод `BakeryItem.fromCsv(String line)`.

## Формат входу

Файл CSV містить по одному товару в одному рядку. Поля в рядку розділяються крапкою з комою, а формат запису має вигляд:

`Назва;Тип;Вага;Собівартість;Ціна`

Приклад коректних рядків:

```text
Хліб пшеничний;хліб;500;22.00;38.00
Печиво;печиво;200;30.00;58.00
```

Файл читається у кодуванні UTF-8. Для чисел допускається як крапка, так і кома як десятковий роздільник (наприклад, `22,50` або `22.50`).

## Правила валідації

Перед внесенням товару до списку перевіряються такі правила:

- кількість полів має дорівнювати 5;
- назва та тип не можуть бути порожніми або складатися лише з пробілів;
- `Вага` має бути цілим числом і не може бути від'ємною;
- `Собівартість` і `Ціна` мають бути числовими, скінченними значеннями і не можуть бути від'ємними;
- порожні поля у будь-якому з обов'язкових стовпців вважаються некоректними;
- якщо формат рядка неправильний, програма записує помилку з номером рядка та поясненням причини.

Некоректні записи не призводять до зупинки програми: вони фіксуються в звіті, а решта даних обробляються далі.

## Збірка та запуск

Для Windows (PowerShell):

```powershell
.\mvnw.cmd verify
.\mvnw.cmd package
java -jar target/kzp-labv25-chyvantukh-1.0.0.jar --input data/input.csv --output data/report.txt
```

Для Windows (Command Prompt):

```cmd
mvnw.cmd verify
mvnw.cmd package
java -jar target/kzp-labv25-chyvantukh-1.0.0.jar --input data/input.csv --output data/report.txt
```

Для macOS та Ubuntu:

```bash
./mvnw verify
./mvnw package
java -jar target/kzp-labv25-chyvantukh-1.0.0.jar --input data/input.csv --output data/report.txt
```

Щоб переглянути версію застосунку:

```bash
java -jar target/kzp-labv25-chyvantukh-1.0.0.jar --version
```

Команда виводить `1.0.0`.

Щоб переглянути довідку про застосунок, доступні параметри та приклад запуску:

```bash
java -jar target/kzp-labv25-chyvantukh-1.0.0.jar --help
```

## Коди завершення

- `0` — успішне виконання;
- `1` — помилка читання вхідного файлу або неправильні аргументи командного рядка;
- `2` — помилка запису звіту.

## Приклад використання

Вхідний файл `data/input.csv` містить дані такого типу:

```text
Хлiб пшеничний;хлiб;500;22.00;38.00
Круасан;кондитерський;90;помилка;55.00
Печиво;печиво;200;30.00;58.00
```

Після запуску:

```bash
java -jar target/kzp-labv25-chyvantukh-1.0.0.jar --input data/input.csv --output data/report.txt
```

програма виводить звіт із такими агрегованими даними:

- загальна вага коректних товарів;
- середній маржинальний прибуток;
- найдорожчий товар;
- перелік некоректних рядків з помилками.

Результат також записується до файлу, вказаного через `--output`.

## Примітка

Проєкт збирається за допомогою Maven Wrapper і потребує Java 21. Для підготовки виконуваного JAR використовується стандартна Maven-конфігурація з `mvnw` / `mvnw.cmd`.
