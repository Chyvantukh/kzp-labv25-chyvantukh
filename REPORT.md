# Звіт до лабораторної роботи № 1

## 1. Тема і варіант

- Предметна область: обробка даних про товари у CSV-файлі.
- Номер варіанта: 25.
- Операційна система: Windows 10.

## 2. Реалізація

У програмі реалізовано обробку даних про товари з файлу `data/input.csv`.
Основні функції:

- зчитування CSV-файлу;
- перевірка коректності кожного рядка;
- відкидання некоректних записів;
- обчислення загальної ваги товарів;
- обчислення середнього маржинального прибутку;
- пошук найдорожчого товару;
- формування текстового звіту в консоль та у файл `data/report.txt`.

Основний клас проєкту — `Main`. Логіка перевірки записів реалізована в
методах `parseLine`, `hasAllFields`, `calculateTotalWeight`,
`calculateAverageMargin` та `findMostExpensiveProduct`.

## 3. Збірка і запуск

Команди для збірки та запуску:

```bash
mvnw.cmd verify
mvnw.cmd package
java -jar target/kzp-labv25-chyvantukh-1.0.0.jar
```

Для macOS та Ubuntu:

```bash
./mvnw verify
./mvnw package
java -jar target/kzp-labv25-chyvantukh-1.0.0.jar
```

## 7. Висновки

Розроблено консольний застосунок для перевірки та обробки даних про товари.
Програма виконує валідацію CSV-рядків, формує звіт про коректні та некоректні записи,

Подальший розвиток проєкту передбачає покращення форматування виводу,
додавання розширених перевірок та створення більш повного набору тестів.
